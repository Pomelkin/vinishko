# Frontend «Своё Вино»

React + TypeScript + Vite. По умолчанию подключён настоящий API.
Полный запуск CPU/GPU — в [корневом README](../README.md).

## Разработка и сборка

Node.js 22.12+:

```powershell
npm ci
npm run dev
npm run build
```

Vite доступен на `http://localhost:5173`; `/api` пересылается на `http://127.0.0.1:8000`.
Другой адрес задаётся `API_PROXY_TARGET` в `.env.local`. Основной API должен быть запущен.
Production-сборку раздаёт nginx в Docker на порту 8080 или FastAPI локально на 8000.
Прямые ссылки и обновление `/scan/:id`, `/wine/:slug` поддерживаются.

```dotenv
VITE_API_MODE=http
VITE_API_BASE_URL=/api
API_PROXY_TARGET=http://127.0.0.1:8000
```

Для демонстрации без серверов задайте `VITE_API_MODE=mock` и перезапустите Vite.
Произвольные фотографии в mock не распознаются; демофото и контуры заданы заранее.
AI-функции в mock не предлагаются. Ключи нельзя помещать в публичные `VITE_*`.

## Возможности

- Камера и галерея; JPEG/PNG/WebP до 20 МиБ и 80 Мп, EXIF, нормализация до 2400 px.
  HEIC предлагается экспортировать в JPEG/PNG.
- Распознавание, выбор по всем контурам бутылки, совпадение и до пяти кандидатов поиска.
  Отказ второго уровня не становится совпадением. F1 и вероятность совпадения не выдумываются.
- Каталог из CSV, поиск по названию, винодельне, сорту и региону; фильтры, по 24 карточки
  с кнопкой продолжения. Отсутствующие характеристики и рейтинги не заполняются фиктивными значениями.
- WhatIs автоматически отправляет кроп выбранной бутылки при открытии блока; если объектов не обнаружено — уменьшенное фото.
- AI-сомелье: исходная карточка CSV, до пяти альтернатив, подсказки, сообщения,
  восстановление и удаление истории. После неоднозначной ошибки сначала загружается история;
  POST автоматически не повторяется. Ответы AI отображаются как текст.

IndexedDB хранит фото и результат: до 10 записей на 7 дней. Reload и возврат из карточки
восстанавливают выбор без повторного распознавания. Если запись запрещена, используется
память вкладки с предупреждением. LocalStorage хранит номер диалога для каждого вина;
история хранится на сервере. Очистка данных браузера удаляет локальные фото и номера диалогов.

Камера на телефоне требует HTTPS с доверенным сертификатом. Обычный адрес локальной сети
по HTTP не подходит для `getUserMedia`; доступен нативный camera input, если его поддерживает браузер.

[API.md](API.md) — контракт, [ARCHITECTURE.md](ARCHITECTURE.md) — устройство интерфейса.
Новые frontend-тесты при интеграции не добавлялись: проверяются сборка и основные действия в браузере.
[qa/VERIFICATION.md](qa/VERIFICATION.md) различает новые проверки и старую историю mock-интерфейса.

Ресурсы макета взяты из предоставленных MHTML и сайта `vino-svoe.ru`; права принадлежат
их правообладателям. Аналитика и сторонние исполняемые скрипты не подключены.
