# Проверки интеграции — 29 сентября 2026

Новые frontend-тесты не добавлялись. Проверки выполнялись при разработке.

- Production-сборка `npm run build` проходит: TypeScript и Vite.
- 21 серверная проверка адаптера, сомелье и whatis проходит без внешних API; проверены маски, реальные строки CSV, отсутствие выдуманных значений, история и ошибки провайдера.
- Все 2046 карточек CSV проверены схемами Zod. Учтены подчёркивания в slug и ошибочные значения крепости.
- В Edge/Chromium при 390×844 проверены каталог из CSV, выдача по 24 карточки, карточка со slug `perovskih_aligote`, прямой URL и обновление страницы, сообщение при отсутствии ключа AI. Использовался локальный проверочный сервер без моделей. Ошибок JavaScript и горизонтального переполнения в этих сценариях не было.
- В браузере дополнительно проверен автоматический whatis при открытии неизвестной бутылки: один запрос, результат без кнопки, восстановление после reload без повторного запроса, отсутствие ошибок JavaScript. Ответ провайдера подменён для проверки поведения UI.
- Обе конфигурации Compose проходят проверку. Образ frontend собран; `nginx -t` успешен. Qdrant запущен; проверка `/readyz` завершилась с кодом 0.

CPU-сборка прошла установку зависимостей и копирование приложения, но Docker Desktop остановился при экспорте образа. GPU-сборка также прервана остановкой Docker. Повторный запуск Docker завершился ошибкой внутреннего соединения `dockerInference`; полноценная сборка образов приложения пока не подтверждена. GPU-проба показала, что в WSL нет доступного NVIDIA-адаптера.

Без ключей и приватных данных не проверены настоящее распознавание SAM3/поиск/второй уровень, картинки S3, ответы OpenRouter, качество и задержки. Модельные ответы в изолированных серверных проверках подменяются; это проверка интеграции, а не точности распознавания. Проверка GPU-инференса требует доступной NVIDIA GPU.

# Проверки frontend

Проверено 19 сентября 2026 в Microsoft Edge / Chromium на Windows через Playwright. Мобильные размеры — **эмуляция**, не физический iPhone и не Safari. Камера проверена на синтетическом MediaStream, а не на физической камере телефона.

## Автоматические проверки

- `npm run build`: TypeScript и production-сборка Vite.
- `npm test`: 18 проверок Vitest / React Testing Library.
- `npm run test:e2e`: 15 браузерных сценариев в `e2e/`, включая EXIF, ограничение 20 МБ и отсутствие `crypto.randomUUID` на HTTP.
- `npm audit`: 0 известных уязвимостей на момент установки зависимостей.

| Область | Проверено |
| --- | --- |
| Геометрия | contain для вертикального и горизонтального фото, смещения, resize, поворот viewport, hit testing по силуэту, пересечения |
| Запросы | отмена в подготовке, AbortSignal, поздний ответ старого запроса, двойное нажатие, ожидание без дублирования, retry того же Blob |
| API | multipart, передача signal, повреждённый ответ, несовпадающие размеры, недопустимые координаты, дубли id, нулевая площадь, offline, 404 |
| Данные | null для неизвестных рейтингов/F1, недопустимая крепость и превышение шкалы рейтинга |

| Фото | JPEG, PNG, WebP, повторный выбор файла, отмена выбора, повреждённый файл, HEIC; отсутствие ложных полигонов на произвольном фото |
| Камера | превью, затвор, пересъёмка, подтверждение, stop tracks, закрытие, отказ разрешения, capture fallback |

Все пять MHTML открыты непосредственно в браузере при 390×844 с отключённым JavaScript. Извлечённые HTML использовались только для анализа ресурсов: сохранённый MHTML точнее сохраняет исходный CSS. Три фотографии iPhone изучены как образец выделения силуэта.

Сравнение рядом: [comparison.html](comparison.html). Дополнительные скриншоты главной сохранены для всех заданных ширин, результат — `result-390.png`.

Осознанные отличия: фильтр имеет зону нажатия 44 px, рядом добавлен ненавязчивый вход в демо; muted-текст немного темнее для контрастности. На результате вместо большой фирменной шапки — компактный возврат, чтобы выбранная бутылка оставалась видна над sheet. Нет iOS-меню Copy/Share и прямоугольных рамок выделения.

## Что не проверялось и требует реального окружения

- Физический iPhone, Safari/WebKit, Android-камера, EXIF всех производителей устройств, реальная экранная клавиатура.
- Реальный backend, сеть до него, качество CV/OCR, near-duplicates, F1 и время инференса. HTTP-адаптер проверен изолированно с подставленными ответами.
- Точность полигонов на произвольных снимках: её здесь нет, это frontend-мок.
- HTTPS-камера на физическом телефоне: порядок настройки описан в README.

Демофото — подготовленные композиции каталожных фотографий с ручной разметкой. Это проверка интерфейса выделения, не доказательство распознавания.
