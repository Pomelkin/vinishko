# Нормализация фото бутылок вина

Прототип предобработки для поиска по фото. Из картинки вырезаются бутылки вина: строго вертикально, горлышком вверх, с запасом 10% и размытым фоном. Если у бутылки видна резкая основная этикетка, отдельно сохраняются её маска и вырезка под OCR. Нормализация ничего не отбрасывает: при ненадёжной маске берётся bbox, а если бутылки нет, в выход идёт целое фото.

```
картинка ─► SAM3 «wine bottle» ─► кандидаты
         ─► логистическая регрессия ─► целевые бутылки
         ─► на каждую: кроп бутылки и JSON
         ─► проверка этикетки (SAM3 «wine label», без крышек и горлышек) ─► маска и вырезка этикетки
         ─► бутылок нет ─► целое фото
```

## Файлы

| Файл | Что делает |
|---|---|
| `normalize.py` | нормализация, есть `--selftest` |
| `normalize.toml` | конфиг, все параметры с комментариями |
| `seg.py` | сегментация SAM3 (запасной вариант YOLO-seg, без этикеток) и метрики этикетки |
| `features.py` | признаки кандидата для отбора |
| `calibrate.py` | калибровка отбора по разметке |
| `calibration.json` | текущие веса и порог отбора |

## Установка

Нужны [uv](https://docs.astral.sh/uv/) и GPU с CUDA. Зависимости ставятся из корня репозитория командой `uv sync`. Веса SAM3 (`sam3.pt`, 3,4 ГБ) кладутся в эту папку. Официальный репозиторий https://huggingface.co/facebook/sam3 закрыт подтверждением доступа, тот же файл открыто лежит на ModelScope:

```bash
curl -L -o sam3.pt "https://modelscope.cn/models/facebook/sam3/resolve/master/sam3.pt"
sha256sum sam3.pt  # 9999e2341ceef5e136daa386eecb55cb414446a00ac2b55eb2dfd2f7c3cf8c9e
uv run --with torch python -c "import torch; torch.load('sam3.pt', weights_only=True, map_location='cpu'); print('ok')"
```

Последняя команда проверяет, что в файле только тензоры. Веса распространяются под SAM License от Meta, в ней есть пункт о торговых ограничениях.

## Запуск

Команды запускаются из корня репозитория:

```bash
N=vinishko.pipeline.steps.normalization
uv run python -m $N.normalize photo.jpg                           # одна картинка
uv run python -m $N.normalize images/ --set output.dir=/data/out  # папка, параметр конфига из командной строки
uv run python -m $N.normalize --selftest                          # проверка геометрии и метрик на синтетике, без модели
uv run python -m scripts.normalize_dataset datasets/<имя>         # разметка датасета в normalization.jsonl, без кропов
```

Из кода: `Normalizer.annotate(path)` отдаёт разметку всех кандидатов без рендера, `Normalizer(img)` отдаёт список `Crop`.

Модель загружается один раз за запуск, около 30 секунд. Дальше около 0,5 с на картинку. Если бутылка в кадре мелкая, этикетка ищется вторым проходом SAM3 по вырезке бутылки, это ещё около 0,35 с на такую бутылку.

## Выход

На каждую бутылку до четырёх файлов рядом, `N` — номер бутылки на картинке. Маска и вырезка этикетки пишутся, только если `label_status` равен `ok`:

| Файл | Что внутри |
|---|---|
| `<имя>_bN.jpg` | кроп бутылки |
| `<имя>_bN.json` | описание, см. ниже |
| `<имя>_bN_label.npz` | маска этикетки, сжатый bool-массив размером с `label_box`: `np.load(path)["mask"]` |
| `<имя>_bN_label.png` | вырезка этикетки под OCR: оригинал в полном разрешении, повёрнут вместе с бутылкой |

```json
{
 "source": "images/DSC_0287_d429be497e.webp",
 "mode": "bottle",
 "bottle_box": [1011, 2202, 2234, 3835],
 "bottle_score": 0.9847,
 "bottle_angle": -34.32,
 "bottle_crop": "DSC_0287_d429be497e_b1.jpg",
 "bottle_crop_matrix": [[0.825905, -0.56381, 797.051182], [0.56381, 0.825905, -2242.088177]],
 "label_status": "ok",
 "label_box": [1305, 2842, 1982, 3538],
 "label_mask": "DSC_0287_d429be497e_b1_label.npz",
 "label_crop": "DSC_0287_d429be497e_b1_label.png"
}
```

Все координаты в пикселях оригинала после EXIF-поворота, боксы `[x1, y1, x2, y2]` включительно. `bottle_crop_matrix` — аффинная матрица 2×3 из оригинала в кроп бутылки. Маска этикетки лежит в боксе этикетки: пиксель оригинала `(x, y)` соответствует `mask[y - y1, x - x1]`.

Поле `mode` показывает, как получен кроп:

| `mode` | Когда | Что в кропе |
|---|---|---|
| `bottle` | обычный случай | поворот, запас, размытый фон |
| `bbox` | маска ненадёжна: длина бутылки меньше `fallback.min_aspect` её ширин | bbox с запасом, без поворота и блюра |
| `full_image` | ни одна бутылка не прошла отбор | целое фото, `bottle_score` равен `null` |

`label_status` равен `ok` или причине из таблицы ниже, для целого фото `no_bottle`. Если этикетка не прошла проверку, поля `label_box`, `label_mask` и `label_crop` равны `null`.

Строгий режим для индексации каталога и обучения: `--set label.required=true --set fallback.full_image=false`. Тогда бутылки без хорошей этикетки не вырезаются, причина остаётся в `status` кандидата в разметке `annotate`.

## Отбор и проверка этикетки

Логистическая регрессия отбирает целевые бутылки среди кандидатов SAM3 по признакам маски и картинки, порог 0.49. Затем проверяется основная этикетка:

| Правило | Параметр | `label_status` |
|---|---|---|
| этикетка закрывает хотя бы 10% площади бутылки | `label.min_cover` | `no_label` |
| этикетка закрывает хотя бы 30% полосы бутылки на своей высоте, то есть не повёрнута боком | `label.min_fill` | `label_partial` |
| этикетка резкая: дисперсия лапласиана от 300 | `label.min_sharpness` | `label_blurry` |
| видимая длина бутылки не меньше 2,6 её ширины | `label.min_length_ratio` | `bottle_hidden` |
| центр этикетки дальше 0,3 длины бутылки от горлышка | `label.min_position` | `label_off_body` |
| короткая сторона этикетки от 40 пикселей оригинала | `label.min_label_px` | `label_too_small` |

Логотип на крышке и кольцевая этикетка на горлышке не считаются: SAM3 отдельно ищет «bottle cap» и «bottle neck», этикетки в этих зонах отбрасываются. Акцизные марки уже 30% ширины бутылки тоже не считаются.

Пороги подобраны на 260 кропах, где видимость и читаемость этикетки отмечены вручную. На них правила отбраковали 63 из 71 бракованной бутылки и потеряли 9 из 189 хороших.

## Калибровка

```bash
uv run python -m vinishko.pipeline.steps.normalization.calibrate                                 # images/ и labels.json в этой папке
uv run python -m vinishko.pipeline.steps.normalization.calibrate --images /data/photos --beta 2  # порог сильнее в пользу полноты
```

Скрипт прогоняет SAM3 по размеченным картинкам, считает 16 признаков кандидатов и обучает логистическую регрессию с групповой кросс-валидацией. Результат пишется в `calibration.json`. Формат разметки:

```json
{"имя.webp": {"decision": "ok", "targets": [{"box": [x1, y1, x2, y2], "truncated": false}]}}
```

`decision` бывает `ok`, `no_target` или `ambiguous`. `truncated` ставится, только если бутылка уходит за край кадра. На 375 размеченных картинках модель даёт точность 0.89 и полноту 0.91, порог по уверенности SAM3 даёт 0.80 и 0.89.

## Ограничения

- **Перспектива.** Бутылка, снятая сверху или сбоку, стоит вертикально по оси, но на глаз выглядит наклонённой.
- **Сцены с множеством бутылок.** На стеллажах и столах отбор ошибается чаще, а второй проход SAM3 по каждой мелкой бутылке заметно добавляет время.
- **Не-вино.** Классификатора вина нет, вино от водки отличают только промпт и уверенность SAM3.
- **Нехватка видеопамяти на WSL.** Если GPU делят несколько процессов, WSL не падает с ошибкой, а переносит данные в системную память, и SAM3 работает в десятки раз медленнее.
