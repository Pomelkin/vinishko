# Подбор похожих товаров, если точная карточка не найдена

Исходная идея: по основной бутылке на фото определить цвет вина и бренд через
DeepSeek без reasoning, затем использовать эти признаки для подбора товаров.
Модель сразу получает закрытые списки всех значений `Категория` и всех брендов
из Каталога. Для каждого признака можно ответить «Не удалось определить».

В Каталоге отдельного поля «бренд» нет, поэтому здесь бренд — каноническое
значение поля `Винодельня`. Оно может отличаться от названия линейки на этикетке:
например, `Di Caspico` → `Дербент Вино`. `Категория` означает цвет вина
(`Белое`, `Красное`, `Розовое`, `Оранжевое`), а не свободный текст поля `Цвет`.

Результат модели — пара признаков, **не** утверждение, что конкретный товар
Каталога найден. `match_products` строит пул товаров: по двум определённым
признакам, при отказе по одному — по оставшемуся. При двух отказах пул пуст.
Функция возвращает все подходящие карточки без произвольного ранжирования;
для выдачи top-N нужен отдельный сигнал релевантности. Eval измеряет и точность
разбора, и наличие исходного товара в пуле, и размер пула.

Модель получает только изображение и списки значений. Путь файла, имя товарной
папки и разметка ей не передаются. Если в кадре несколько бутылок, основная —
центральная, при неясном центре — самая крупная. Каждый ответ проходит локальную
проверку по Каталогу; ошибочный формат или постороннее значение считается сбоем,
а не успешным отказом.
