# Нормализация фото бутылок вина

Прототип предобработки для поиска по фото. На вход подаётся произвольная картинка, на выходе получается кроп каждой целевой бутылки: строго вертикально, горлышком вверх, с запасом 10% по краям и размытым фоном. Бутылка без видимой этикетки считается бракованной и не вырезается. К каждой картинке пишется JSON с описанием того, как получен каждый кроп.

```
картинка ─► SAM3 «wine bottle» ─► кандидаты (маски)
         ─► SAM3 «wine label» на тех же признаках ─► этикетки
         ─► логистическая регрессия по признакам ─► целевые бутылки
         ─► без видимой этикетки ─► отказ no_label
         ─► для каждой оставшейся: поворот по оси маски, кроп с запасом, блюр фона по антимаске
         ─► <имя>_b1.jpg, <имя>_b2.jpg, … + <имя>.json
```

## Файлы

| Файл | Что делает |
|---|---|
| `normalize.py` | Нормализация: сегментация, отбор, геометрия, выход. Есть `--selftest` |
| `normalize.toml` | Конфиг нормализации, все параметры с комментариями |
| `seg.py` | Сегментация SAM3 и проверка этикетки, запасной вариант YOLO-seg без проверки этикетки |
| `features.py` | Признаки кандидата для отбора, общие для нормализации и калибровки |
| `calibrate.py` | Калибровка отбора по разметке |
| `calibration.json` | Текущие веса логистической регрессии и порог |

В репозиторий не входят картинки, разметка, веса моделей и результаты прогона. Они перечислены в `.gitignore`.

## Установка

Нужны [uv](https://docs.astral.sh/uv/) и GPU с CUDA. Зависимости каждого скрипта описаны в его шапке, `uv` ставит их при первом запуске.

Веса SAM3 (`sam3.pt`, 3,4 ГБ) кладутся в эту папку. Официальный источник закрыт ручным подтверждением доступа: https://huggingface.co/facebook/sam3. Тот же файл открыто лежит на ModelScope в организации «AI at Meta»:

```bash
curl -L -o sam3.pt "https://modelscope.cn/models/facebook/sam3/resolve/master/sam3.pt"
sha256sum sam3.pt  # 9999e2341ceef5e136daa386eecb55cb414446a00ac2b55eb2dfd2f7c3cf8c9e
uv run --with torch python -c "import torch; torch.load('sam3.pt', weights_only=True, map_location='cpu'); print('ok')"
```

Последняя команда загружает файл в режиме «только тензоры» и проверяет, что в pickle нет исполняемого кода. Веса распространяются под SAM License от Meta. В ней есть пункт о торговых ограничениях, его стоит проверить перед коммерческим использованием.

## Нормализация

```bash
./normalize.py photo.jpg                          # одна картинка
./normalize.py images/ --set output.height=1024   # папка, с переопределением параметра
./normalize.py --selftest                         # проверка геометрии и покрытия этикеткой на синтетике, без модели
```

Результат пишется в `out/`. Модель загружается один раз на запуск, это около 30 секунд. Дальше время на картинку такое, замер на RTX 4070, которую параллельно грузил другой процесс:

| Этап | Время |
|---|---|
| SAM3: кодирование картинки и запрос бутылок | ~560 мс, на свободной карте ~220 мс |
| SAM3: запрос этикетки на тех же признаках | ~75 мс |
| Признаки и отбор | ~10 мс |
| Поворот, кроп, блюр | единицы мс, до ~300 мс на больших кропах |

### Конфиг

Все параметры описаны в `normalize.toml`, любой переопределяется флагом `--set секция.ключ=значение`. Главные:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `segmentation.prompt` | `wine bottle` | текстовый промпт SAM3 |
| `selection.threshold` | `-1` | порог отбора, `-1` берёт порог из `calibration.json` (0.49) |
| `selection.max_bottles` | `0` | максимум бутылок с картинки, `0` без ограничения |
| `label.enabled` | `true` | отбраковывать бутылки без видимой этикетки |
| `label.prompt` | `wine label` | промпт SAM3 для этикетки |
| `label.min_conf` | `0.4` | этикетки ниже этой уверенности не учитываются |
| `label.min_cover` | `0.10` | минимальная доля площади бутылки под этикеткой |
| `orientation.upright_within_deg` | `30` | почти вертикальная бутылка считается стоящей горлышком вверх |
| `crop.padding_x`, `crop.padding_y` | `0.10` | запас с каждой стороны, доля ширины и высоты бутылки |
| `background.mode` | `blur` | `blur`, `color` или `none` |
| `output.height` | `0` | высота выходного кропа, `0` сохраняет родное разрешение |

Если поменять параметры секции `[segmentation]`, калибровку нужно пересчитать. Иначе `normalize.py` предупредит, что веса обучены под другие настройки сегментации.

### Как определяется горлышко

Ось бутылки находится методом главных компонент по маске. Дальше порядок такой:

1. Если ось отклоняется от вертикали не больше чем на `upright_within_deg`, горлышком считается верхний конец. На фото бутылки почти никогда не стоят вверх ногами. Профиль ширины на таких кадрах ошибался из-за дыр в маске от бликов и этикеток.
2. Иначе горлышко ищется по профилю ширины маски: это более узкий конец. Так обрабатываются бутылки, из которых наливают, и бутылки на стойках.
3. Если концы маски почти одной ширины, горлышком считается верхний конец.

В JSON способ записан в поле `neck_method`: `upright_prior`, `profile` или `up`.

### Проверка этикетки

Бутылка без видимой этикетки не годится для идентификации, поэтому она получает отказ со статусом `no_label`. После запроса бутылок SAM3 получает второй запрос «wine label» на тех же признаках картинки. Самая дорогая часть, кодирование изображения, повторно не выполняется. Отдельный запрос нужен потому, что совместный промпт «бутылка + этикетка» менял набор найденных бутылок, а калибровка отбора обучена на бутылках без него.

Этикетка засчитывается бутылке, если не меньше половины её площади лежит внутри маски бутылки. Видимость определяется долей площади бутылки, которую закрывают такие этикетки с уверенностью от `min_conf`. В JSON эти величины записаны как `label_conf` и `label_cover`.

Пороги подобраны на 260 кропах из прогона по датасету: 200 случайных и 60 из сцен с несколькими бутылками. Видимость этикетки отмечена вручную, у 33 бутылок её нет. Пустая наклейка без надписей считалась видимой этикеткой.

| Бутылки в выборке | Отбракованы | Прошли |
|---|---|---|
| Без этикетки, 33 | 24 | 9 |
| С этикеткой, 227 | 2 | 225 |

Порог покрытия 10% взят с запасом. Бутылки со слабо видимой этикеткой лежат плотной группой около 13–19% покрытия: при пороге 15% отбраковывается 27 бутылок без этикетки, но теряются 3 хорошие, при 20% уже 10.

### Выходной JSON

Один файл на входную картинку. Сокращённый пример:

```json
{
  "status": "ok",
  "source": {"path": "…", "sha256": "…", "width": 2000, "height": 1336},
  "segmentation": {"model": "sam3.pt", "prompt": "wine bottle", "label_prompt": "wine label", "n_candidates": 3},
  "selection": {
    "threshold": 0.49,
    "candidates": [
      {"candidate": 1, "conf": 0.926, "box": [246, 377, 309, 648], "score": 0.6834, "label_conf": 0.896, "label_cover": 0.375, "status": "selected"},
      {"candidate": 2, "conf": 0.904, "box": [359, 377, 406, 574], "score": 0.1471, "label_conf": 0.329, "label_cover": 0.0, "status": "below_threshold"}
    ]
  },
  "bottles": [{
    "output": "02_33883f518a_b1.jpg",
    "candidate": 1, "score": 0.6834, "label_conf": 0.896, "label_cover": 0.375,
    "angle_deg": -1.25, "neck_method": "upright_prior",
    "neck_point": [272.4, 377.9], "base_point": [278.3, 646.0],
    "bottle_size_px": [60.8, 267.7], "padding_px": [6.1, 26.8],
    "out_of_bounds_frac": 0.0,
    "matrix_src_to_dst": [[0.99976, -0.021899, -227.49], [0.021899, 0.99976, -357.01]],
    "matrix_dst_to_src": [[0.99976, 0.021899, 235.25], [-0.021899, 0.99976, 351.94]],
    "width": 73, "height": 322
  }],
  "config": {"…": "полный конфиг запуска"},
  "timing_ms": {"decode": 27, "segmentation": 557, "selection": 9, "render": 2, "total": 600}
}
```

Координаты даны в пикселях оригинала после применения EXIF-поворота. Матрица `matrix_src_to_dst` аффинная, размером 2x3: точка оригинала `[x, y, 1]` переходит в точку кропа, обратная матрица переводит обратно. Статусы кандидатов проверяются в таком порядке: `below_threshold` или `empty_mask`, затем `no_label`, `over_max_bottles`, `too_small`, иначе `selected`. Если ни одна бутылка не прошла отбор, `status` равен `no_bottles`.

## Калибровка

```bash
./calibrate.py                                   # images/ и labels.json в этой папке, beta=1.5
./calibrate.py --images /data/photos --beta 2    # другая папка, порог сильнее в пользу полноты
```

Скрипт прогоняет SAM3 по размеченным картинкам с настройками из `normalize.toml`, поэтому калибровка и нормализация видят одних и тех же кандидатов. Для каждого кандидата считаются 16 признаков: уверенность, площадь, вытянутость маски, касание края кадра, резкость внутри маски, салиентность, центральность, скученность. Затем обучается логистическая регрессия с групповой кросс-валидацией, чтобы кадры одной серии не попадали и в обучение, и в проверку. Порог подбирается по F-бета. Результат пишется в `calibration.json`, признаки в `features.jsonl`.

Разметка в `labels.json` описывает целевые бутылки на каждой картинке:

```json
{"имя.webp": {"decision": "ok", "targets": [{"box": [x1, y1, x2, y2], "truncated": false}]}}
```

`decision` принимает значения `ok`, `no_target` и `ambiguous`, неоднозначные картинки пропускаются. Бутылка помечается `truncated`, только если часть её уходит за край кадра. Заслонённая рукой, бокалом или ведёрком бутылка считается целой. Кандидат SAM3 положительный, если его бокс совпал с целой целевой бутылкой по IoU от 0.7.

Результат на 375 размеченных картинках, где 1908 кандидатов и 352 целевые бутылки:

| Метод | Точность | Полнота | F1 | Трудных картинок решено целиком |
|---|---|---|---|---|
| Порог по уверенности SAM3 | 0.80 | 0.89 | 0.84 | 63% |
| Логистическая регрессия, порог 0.49 | 0.89 | 0.91 | 0.90 | 77% |

Трудными считаются картинки, где SAM3 нашёл два и больше кандидата. Градиентный бустинг даёт то же самое, F1 0.91, поэтому оставлена линейная модель. Самые сильные признаки: касание края кадра со знаком минус, площадь маски и уверенность SAM3.

Цена понижения порога: при 0.35 полнота 0.93, точность 0.83. Модель найдёт на 8 бутылок больше, но добавит 28 лишних.

## Ограничения

- **Перспектива.** Бутылка, снятая сверху или сбоку, стоит вертикально по оси, но на глаз выглядит наклонённой: видно эллипс дна и скошенную этикетку.
- **Сильный наклон.** У бутылок, смотрящих горлышком вниз под углом 90–150°, примерно каждая пятая развёрнута неверно.
- **Отбор.** Основные ошибки в сценах с десятком бутылок: стеллажи, столы, ящики. Там модель берёт не те бутылки или пропускает нужные.
- **Этикетка на снимках дна.** Выдавленный узор на дне бутылки SAM3 принимает за этикетку, такие кадры проходят проверку.
- **Размытые этикетки.** Этикетка, которая видна белым пятном, но не читается, считается видимой.
- **Не-вино.** Классификатора вина нет. Отличить вино от водки помогают только промпт SAM3 и его уверенность.
- **Выборка.** Около двух третей разметки взято подряд по алфавиту, а не случайно, поэтому метрики могут быть оптимистичны.
- **Нехватка видеопамяти на WSL.** Если GPU делят несколько процессов и видеопамяти не хватает, WSL не падает с ошибкой, а переносит данные в системную память, и SAM3 работает в десятки раз медленнее.
