# Данные для загрузки

Для заполнения коллекций используйте две готовые папки. Изображения в каждой
папке лежат непосредственно в `images/`; в CSV указано их имя. Для перехода
со старых S3-ключей изображения копируются **внутри S3**, без повторной
загрузки файлов с диска.

| Папка | CSV | Изображения | Назначение |
| --- | --- | --- | --- |
| `catalog/` | `catalog.csv` | `images/` | 2 103 карточки Каталога; 2 055 карточек с проверенным изображением |
| `test/` | `test.csv` | `images/` | 176 размеченных фото для проверки |

В `catalog.csv` одна строка соответствует одному `Slug`. Карточка содержит сведения о вине, нормализованные свойства, `image_filename` и `near_duplicate_group_slug`. `image_filename` — имя файла в `catalog/images/`; новый S3-ключ имеет вид `data/catalog/images/<image_filename>`. Пустое значение означает, что у карточки нет проверенного Эталона. Такие карточки остаются в Каталоге и могут находиться по тексту.

`near_duplicate_group_slug` — slug представителя связной группы визуально близких **разных** вин. Представителем выбран лексикографически минимальный `Slug` группы. Все вина, связанные цепочкой подтверждённых пар, имеют одинаковое значение; пустое значение означает отсутствие группы. Всего 352 группы, охватывающие 1 226 карточек. Одна карточка принадлежит не более чем одной группе.

В `test.csv` ровно два столбца: `image_filename` и `slug`. `image_filename` — имя файла в `test/images/`; новый S3-ключ имеет вид `data/test/images/<image_filename>`. Для 135 фото `slug` содержится в Каталоге; для 41 фото вина вне Каталога `slug` пустой. Публичный пакет `eval/` не имеет ключа ответов и в `test.csv` не включён.

Сценарий загрузки допускает дополнительный S3-префикс перед `data/`. Если при прежней загрузке был задан `-Prefix`, его нужно добавить к ключу при чтении объекта.

`near_duplicates/` хранит проверенные пары и галерею для аудита групп, повторно загружать её на S3 не нужно. `technical/` содержит Медиа-дамп, нормализованный источник, журналы и промежуточные файлы. `legacy/` хранит старые раскладки тестовых данных. `eval/` — неизменяемый пакет внешней оценки. Эти папки не входят в две готовые поставки.

Проверка связей CSV с изображениями и группами: `python scripts/export_final_data.py --check`. Исходные данные для повторного экспорта лежат в `technical/` и `legacy/`; генерация новой поставки требует пустого каталога назначения.
