# Правило работы с сервисом

- Во время разработки и проверки сервис можно запускать.
- Перед каждым финальным ответом пользователю останови сервис этого проекта, если он запущен. Для Docker Compose используй `docker compose stop ocr`; локально запущенный `uvicorn` также останови.
- Проверь, что сервис больше не работает. Не оставляй его запущенным после завершения задачи.
