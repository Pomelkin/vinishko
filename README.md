# vinishko

Мобильный frontend сканера «Своё Вино» находится в [`frontend/`](frontend/README.md).

```powershell
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173. По умолчанию включена демонстрация с локальными данными; реальное распознавание требует backend. API-контракт, архитектура, камера на телефоне и проверки описаны в документации frontend.

Существующие Python-модули в `vinishko/`, `scripts/` и их конфигурация сохранены.
