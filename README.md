# Винишко

## Откуда берутся кропы

Каталог и тест содержат исходные фотографии. Предварительно вырезать бутылки и добавлять кропы в эти папки не нужно.

| Когда | Что делает нормализация | Где оказывается кроп |
| --- | --- | --- |
| Запрос по фото из теста | При обычном запуске создаёт `BottleCrop` с `crop` этикетки и `box_crop` всей бутылки | В памяти пайплайна; отладочный запуск сохраняет оба кропа в `runs/<фото>/normalization/` |
| Сборка индекса каталога | Создаёт два кропа для каждого принятого фото каталога | В хранилище `images` сохраняет `box_crop`; в Qdrant записывает вектор выбранного `encoder_input` и метаданные |
| Подготовка данных для обучения | Записывает маски и угол в `normalization.jsonl` | Файл кропа не создаётся: загрузчик обучения строит его при чтении исходного фото |

При повторном поиске с `--skip-normalization` пайплайн читает сохранённые кропы. Текущий конфиг использует коллекцию `catalog_vitl16_1024` в Qdrant и локальную копию каталожных кропов `datasets/local/normalized/catalog/images`. Для старых записей без `image_crop=bottle_box` он берёт исходные эталоны из `datasets/local/catalog/images`. Вход энкодера задаёт `encoder_input`: `crop` для DINO либо `box_crop` для моделей, обученных на изображении всей бутылки. Сборку новой коллекции запускайте с отдельным конфигом, в котором заданы собственные имя коллекции и хранилище `images`.

Подробности: [запуск пайплайна](vinishko/pipeline/README.md), [нормализация](vinishko/pipeline/steps/normalization/README.md), [сборка и поиск по каталогу](vinishko/pipeline/steps/vis_searcher/README.md), [обучение энкодера](vis_seacher_training/README.md).
