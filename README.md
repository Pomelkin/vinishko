# Винишко

## Откуда берутся кропы

Каталог и тест содержат исходные фотографии. Предварительно вырезать бутылки и добавлять кропы в эти папки не нужно.

| Когда | Что делает нормализация | Где оказывается кроп |
| --- | --- | --- |
| Запрос по фото из теста | При обычном запуске создаёт `BottleCrop` из исходного фото | В памяти пайплайна; отладочный запуск сохраняет кроп в `runs/<фото>/normalization/` |
| Сборка индекса каталога | Создаёт один кроп для каждого принятого фото каталога | В отдельном хранилище `images` из конфига сборки; в Qdrant записываются вектор и метаданные |
| Подготовка данных для обучения | Записывает маски и угол в `normalization.jsonl` | Файл кропа не создаётся: загрузчик обучения строит его при чтении исходного фото |

При повторном поиске с `--skip-normalization` пайплайн читает сохранённый кроп. Текущий конфиг поиска рассчитан на уже собранную коллекцию Qdrant и локальные исходные фото `datasets/local/catalog/images` для показа кандидатов. Он не загружает каталожные кропы из S3. Сборка новой коллекции требует отдельного конфига с `images`, поскольку в текущем конфиге стоит `images: null`. Комментарий с S3-префиксом в конфиге — пример настройки, а не подтверждение места хранения уже созданных кропов.

Подробности: [запуск пайплайна](vinishko/pipeline/README.md), [нормализация](vinishko/pipeline/steps/normalization/README.md), [сборка и поиск по каталогу](vinishko/pipeline/steps/vis_searcher/README.md), [обучение энкодера](vis_seacher_training/README.md).
