## Покрытие Каталога

По именам удаётся найти изображение для **2 097 из 2 103 позиций (99,7%)**.
Это ещё не означает, что каждому найденному файлу можно доверять: нормализатор
проверяет общий SHA-256 у семантически разных товаров и исключает конфликтные
привязки. Итог для CV-индекса:

| Статус изображения | Позиций |
|---|---:|
| `ok_exact` | 2 032 |
| `ok_collision_owner` | 15 |
| `ok_shared_same_product` | 8 |
| **Допущено в индекс** | **2 055 (97,7%)** |
| `excluded_image_collision` | 40 |
| `excluded_wrong_product_image` | 2 |
| `missing` | 6 |

Конфликтных SHA-групп — 27. У 6 позиций нет найденного изображения; ещё 40
имеют конфликтную привязку и 2 показывают другой товар на индивидуальном файле.
Эти 42 позиции требуют исправления привязки либо отдельного Эталона. Приоритет фотографии из
Каталога остаётся важным, а OCR по этикетке нужен для сортов, годов и сахара в
визуально близких семействах. Отсутствие изображения теперь не является массовой
дырой в Каталоге, как казалось по первому тому.

Две индивидуальные ошибки обнаружены при визуальной проверке near-duplicates:
красный Fiori di Mare показывал светлое игристое, а LETO Cabernet Franc Reserve
2020 — белую бутылку LE10 без надписи Reserve. Исходные файлы сохранены;
`data/technical/strapi/image_mismatch_reviews.csv` блокирует их по точному SHA-256 при
повторной сборке Каталога.

У рабочей выборки связанных файлов медианная ширина бутылки около 316 px;
1 378 из 2 222 файлов имеют бутылку шириной менее 400 px. Мелкий винтаж следует
читать на кропе этикетки в исходном разрешении.

В Публичном eval-сете по-прежнему нет ключа ответов. Два целевых вина отсутствуют
в Каталоге; позиция Массандры «Мускатель белый» теперь имеет Эталон. Поэтому три
полевых фото годятся для smoke-теста API, но не для оценки F1.
